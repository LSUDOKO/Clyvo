# Clyvo

an ecommerce website backend

## Commands

- build: `go build ./...`
- test: `go test ./...`

## Layout

- `controller/`
- `databases/`
- `middlewares/`
- `models/`
- `routes/`
- `tokens/`

## Rules

- Run `go test ./...` before you say a change is done.
- Never commit secrets or `.env` files.
